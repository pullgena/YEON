# YEON KeyView v1.7.0 — 크기 조절 지원

Windows에서 실제 키보드와 마우스 입력을 보라색·마인크래프트·할로윈 등의 테마로 보여주는 입력 오버레이입니다. 이제 표시창을 확대·축소할 수 있습니다.

## 창 크기 조절

- **오른쪽 아래 작은 삼각형을 마우스로 드래그** → 비율을 유지하며 크기 조절
- **Ctrl + 마우스 휠** (포인터를 KeyView 창 위에 올린 상태) → 10%씩 확대·축소
- **창 우클릭 → 크기 조절** → 50%, 75%, 100%, 125%, 150% 사전 설정
- **Windows 시스템 트레이 → 크기 조절** → 메뉴로 조정. 게임 중 **마우스 클릭 통과**가 켜져 있으면 트레이에서 조절

범위는 **50~150%**, 최소 5% 단위이며 화면 밖으로 넘치지 않도록 실제 창 크기는 화면 공간에 맞춰 제한됩니다. 전체 104키 화면이 큰 경우 150%로 선택해도 화면보다 커지지 않습니다.

**세 가지 키보드 모드(Shift+1 사진 16키, Shift+2 WASD+Space, Shift+3 전체 104키)가 같은 확대 비율을 사용합니다.** 테마 변경이나 모드 전환 후에도 배율은 유지됩니다. 확대·축소 시 키보드 및 마우스 카운터는 초기화되지 않습니다.

설정은 `%APPDATA%\YEON\KeyView\zoom.json`에 **배율 숫자만** 저장되어 재실행 후에도 유지됩니다. 기존 테마 저장은 `settings.json`에서 계속 관리합니다.

## 마크 플레이 최적화 유지

- 변경된 키만 화면 갱신하고, 기본 마인크래프트 최적화 모드가 활성화됨
- 마우스 이동은 고빈도 전역 훅이 아닌 낮은 빈도 확인으로 표시
- 백그라운드 시스템 트레이 동작, 키/마우스 입력 카운터, 테마 6종 모두 유지
- 선택적으로 **마우스 클릭 통과**를 켜면 게임 조작을 가로채지 않습니다. 클릭 통과 시 드래그·Ctrl+휠 대신 트레이 메뉴를 이용합니다.

## 다운로드

[YEON KeyView GitHub Releases](https://github.com/pullgena/YEON/releases)에서 최신 `YEON-KeyView.exe`를 다운로드합니다.

개발 및 테스트: Windows / Python 3.12+

```powershell
cd keyview
py -m pip install -r requirements.txt
py -m unittest discover -s tests -p "test_*.py"
py app.py
```

Windows의 DPI/디스플레이 배율에 따라 글씨의 상대적인 크기가 조금 다르게 보일 수 있으며, 특수 게임 입력 또는 안티치트에 따라 일부 키가 감지되지 않을 수 있습니다.
