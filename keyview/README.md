# YEON KeyView v1.5.0 — 할로윈·마인크래프트 테마

실제 키보드(104키)와 마우스 입력을 화면 옆에서 보여주는 Windows 오버레이 앱입니다.
**테마 변경**으로 색깔과 디자인을 선택할 수 있으며, 이전 단축키·KPS·Total·저렉 갱신·시스템 트레이 백그라운드 실행 기능을 유지합니다.

## 테마 6종

| 테마 | 디자인 |
|---|---|
| 🎃 **할로윈** | 짙은 밤색·호박색 테두리·보라 포인트 |
| ⛏ **마인크래프트** | 잔디 블록에서 영감을 받은 초록색·흙색, 네모난 픽셀 느낌 |
| 💜 **기본 퍼플** | 이전 사진의 검정·보라색 네온 |
| ⚡ **사이버** | 어두운 배경에 청록색 네온·핑크 포인트 |
| ❄ **겨울** | 차분한 파란색·얼음빛 테두리 |
| 🌸 **벚꽃** | 진한 분홍·연분홍 컬러 |

**2026년 10월에는 처음 설치 시 할로윈 테마가 기본 적용**됩니다. 11월 이후 처음 설치하면 기본 퍼플 테마로 시작합니다.
단, 한 번이라도 직접 고른 테마는 계절과 관계없이 재실행 후에도 유지됩니다. 날짜에 따라 사용자가 선택한 테마를 임의로 바꾸지 않습니다.

## 테마 변경 방법

1. 오버레이 창에서 **마우스 오른쪽 버튼 클릭 → 테마 변경 → 원하는 테마 선택**
2. 또는 Windows 작업 표시줄의 **보라색 K 아이콘(시스템 트레이) → 테마 변경**을 선택

**테마만 변경되며 KPS, Total, 키별 횟수는 초기화되지 않습니다.**
설정 파일에는 테마 이름만 저장합니다: `%APPDATA%\YEON\KeyView\settings.json`.

## 키보드 모드

- **Shift + 1**: 보내주신 사진과 같은 16키 키보드
- **Shift + 2**: W·A·S·D + Space
- **Shift + 3**: 전체 ANSI 104키 키보드

모든 키보드 모드 아래에 **마우스 클릭(LMB·MMB·RMB), 스크롤(▲·▼), 이동(MOVE)** 입력 표시가 함께 나옵니다.
전체 화면을 반복해서 그리지 않고 **입력에 따라 필요한 요소만 갱신**하도록 최적화되어 있습니다.
마우스 움직임 표시도 초당 약 8회까지만 처리합니다.

## 실행 및 빌드 (Windows)

[GitHub 릴리스에서 Windows EXE 받기](https://github.com/pullgena/YEON/releases)

```powershell
cd keyview
py -m pip install -r requirements.txt
py -m unittest discover -s tests -p "test_*.py"
py app.py
```

변경 사항을 저장소에 업로드하면 GitHub Actions가 Windows EXE를 자동으로 빌드하고 아티팩트 및 KeyView 전용 릴리스로 배포합니다.

## 개인정보와 주의사항

테마 선택 외에는 입력 기록(문장, 비밀번호, 마우스 위치)을 디스크에 저장하지 않으며, 네트워크로 전송하지 않습니다. 키별 카운트는 실행 중 메모리에만 저장됩니다. 중요한 작업을 할 때는 **입력 감지 중지**를 이용할 수 있습니다.
게임 안티치트·키보드 드라이버·Windows 권한에 따라 일부 키가 감지되지 않을 수 있습니다.
