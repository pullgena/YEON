# YEON KeyView v1.6.0 — Minecraft Game Optimization

실제 키보드(ANSI 104키)와 마우스를 보여주는 Windows 오버레이입니다. 마인크래프트 Java Edition 26.3에서 게임 중 부담을 줄이도록 최적화했습니다.

## 마크 플레이 최적화 (기본 ON)

- **키 변화만 그리기**: 기존 캔버스의 104키를 매번 순회하는 대신 눌리거나 떼어진 키, 표시가 끝날 키, Shift 기호, 하단 카운터만 검사합니다.
- **적응형 UI 주기**: 입력 중 64ms(약 16회/초), 화면이 조용할 때 140ms, 트레이로 숨긴 경우 320ms 간격. 일시정지 없이 계속 고정 높은 프레임으로 그리지 않습니다.
- **마우스 이동 훅 제거**: 마우스 움직임 이벤트를 초당 수백~수천 번 Python에 전달하지 않습니다. 표시창이 보일 때에만 약 240ms 간격으로 포인터 위치를 가볍게 확인합니다. 움직임 감지 표시만 줄어들 뿐 클릭·스크롤은 계속 표시합니다.
- **메모리**: 기존 입력 횟수는 실행 중 메모리에만 보관하고, 마우스 좌표는 저장하지 않습니다. 타이핑 내용도 저장하지 않습니다.
- **게임 최적화 모드 ON/OFF**: 창 우클릭 또는 시스템 트레이 메뉴에서 바꿀 수 있습니다. 기본값은 ON입니다.
- **선택형 마우스 클릭 통과**: 게임 도중 오버레이가 클릭을 받지 않도록 Windows 창 스타일을 변경합니다. 기본값은 OFF이며 **시스템 트레이에서 다시 해제**할 수 있습니다. 클릭 통과를 켜면 오버레이를 마우스로 드래그하거나 우클릭 메뉴를 열 수 없으므로 시스템 트레이를 사용하세요.

## 마인크래프트 26.3에서 표시가 안 될 때

마인크래프트 26.3의 기본 전체 화면은 **테두리 없는 전체 화면(Borderless Fullscreen)**이고, 마우스 이동은 **상대 마우스 모드**로 처리됩니다. 키보드 오버레이를 보려면 우선 **창 모드 또는 테두리 없는 전체 화면**으로 실행해 보세요. **독점 전체 화면(Exclusive Fullscreen)**에서는 Windows 오버레이가 가려질 수 있습니다. 게임·Windows 환경마다 오버레이 노출 여부는 다르므로 100% 화면 위 표시를 보장하지는 않습니다.

마인크래프트 플레이 중 마우스를 움직여 카메라를 돌리는 조작은 Windows 포인터 좌표 변화로 잡히지 않을 수 있습니다. **LMB/RMB/MMB 클릭 및 스크롤 표시는 계속 사용**할 수 있도록 설계했지만 게임별 입력 경로·권한에 따라 확인이 필요합니다.

## 기존 기능

- **Shift+1**: 사진 속 16키 표시 / **Shift+2**: WASD + Space / **Shift+3**: 104키
- 마우스 LMB·MMB·RMB·스크롤·MOVE 표시, 키별 입력 횟수, KPS 및 Total
- 6종 테마: 할로윈, 마인크래프트, 기본 퍼플, 사이버, 겨울, 벚꽃. 이전 선택한 테마 유지
- 창 항상 위(기본 켜짐), 화면 이동, 백그라운드 실행(시스템 트레이), 카운터 초기화
- 전역 키 입력은 **읽기 전용**으로 사용하며 게임 입력을 차단하지 않습니다.

## 설치

[GitHub Releases](https://github.com/pullgena/YEON/releases)에서 `YEON-KeyView.exe`를 다운로드한 후 실행하세요.

```powershell
cd keyview
py -m pip install -r requirements.txt
py -m unittest discover -s tests -p "test_*.py"
py app.py
```

설정 저장 시 테마 ID만 기록됩니다. Windows 시작 시 자동 실행은 별도로 등록하지 않습니다.
