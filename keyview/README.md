# YEON KeyView v1.4.0 — 키보드 + 마우스 입력 표시

Windows에서 키보드와 마우스 입력을 보라색 오버레이로 시각화합니다.
기존 키보드 **Shift+1·Shift+2·Shift+3** 화면 전환과 시스템 트레이 백그라운드 실행 기능을 유지했습니다.

## 화면 전환
- **Shift+1** → 이전에 보내주신 사진과 같은 16개 키 + KPS·Total
- **Shift+2** → 게임용 W·A·S·D + Space
- **Shift+3** → ANSI 104키 전체 배열

모든 화면 아래에 **MOUSE** 표시줄이 나타납니다.
- **LMB / MMB / RMB**: 마우스 왼쪽/가운데(휠 클릭)/오른쪽 클릭에 반응, 각각 횟수 표시
- **▲ / ▼**: 스크롤 위/아래를 별도로 표시하고 이벤트별 횟수 기록
- **MOVE**: 마우스를 움직이면 잠깐 강조됨. 마우스 좌표/경로는 저장하지 않음
- **MOUSE 아래 숫자**: 왼쪽·가운데·오른쪽 클릭과 휠 이벤트의 합계

**KPS와 Total은 기존처럼 키보드 입력만 계산**합니다. 마우스 합계는 별도로 표시됩니다.

## 렉 감소 및 개인정보 보호

기존 v1.3의 변경된 키만 갱신하는 방식을 유지합니다. 마우스 움직임은 최대 약 **초당 8번** 표시하도록 제한하며, 이동 좌표와 입력 문자열은 저장하거나 전송하지 않습니다. 마우스 스크롤은 하드웨어/드라이버가 발생시키는 이벤트 1건을 1회로 계산하므로 실제 휠의 물리적인 칸 수와 다를 수 있습니다.

## 조작
- 키보드 표시창 마우스 드래그 → 창 이동
- 표시창에서 오른쪽 버튼 → 화면 선택, 카운터 초기화, 감지 중지, 숨기기, 종료
- 백그라운드로 숨기면 시스템 트레이 아이콘에서 다시 열 수 있음
- **입력 감지 중지**를 선택하면 키보드·마우스 전역 감지가 모두 멈춤
- **완전히 종료**를 선택하면 전역 후킹과 프로그램이 종료됨

## GitHub Windows 빌드

[GitHub Releases](https://github.com/pullgena/YEON/releases)에서 `YEON-KeyView.exe`를 받으실 수 있습니다.

소스 실행 (Windows / Python 3.12+):
```powershell
cd keyview
py -m pip install -r requirements.txt
py -m unittest discover -s tests -p "test_*.py"
py app.py
```

마우스 및 키보드 입력 감지는 Windows 앱 권한, 게임 안티치트, 장치 드라이버에 따라 제한될 수 있습니다. Windows 시작 시 자동 실행은 아직 적용하지 않았습니다.
