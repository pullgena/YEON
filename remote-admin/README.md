# YEON 원격 조정 — 관리자 v1.3.7

- 더블 클릭하면 관리 제어판을 자동 실행합니다.
- 왼쪽 **내 컴퓨터 목록**에서 저장된 관리 대상 PC의 이름을 클릭하면 해당 원격 조정 창이 열립니다. 이름은 8자리 PIN 인증 후 관리 대상 PC에서 안전하게 가져옵니다. IP 주소만 저장하며 PIN은 저장하지 않습니다.
- 해당 관리 대상 PC에서 명시적으로 **공유 시작**을 눌러야 접속할 수 있습니다. 같은 신뢰하는 LAN 내에서만 연결 가능합니다.
- 관리자 제어판에서 원격 입력을 **ON/OFF**로 관리합니다. OFF 시 화면만 보여 주며 기본 OFF입니다.
- 원격 화면에서 입력 칸(구글 검색창 등)을 클릭한 후 **키보드로 직접 타이핑**합니다. 한글 IME와 영문 입력 지원. 클릭으로 원격 화면에 키보드 포커스가 이동하며 빠른 조작도 지원합니다.
- 관리자 앱의 **X 버튼**을 누르면 프로그램은 종료되지 않고 **Windows 알림 영역(시스템 트레이)**에 남습니다. 트레이 아이콘을 클릭해 제어판을 다시 열거나 우클릭해서 연결 중지/완전 종료할 수 있습니다.
- **집중 화면 전송**은 관리 대상 사용자가 현장에서 승인해야 실행되며 ESC로 긴급 종료할 수 있습니다.
- 관리자 앱을 완전히 종료하거나 연결 종료하면 원격 제어 ON 권한을 해제합니다.

관리자용 `YEON-Remote-Admin-v1.3.7.exe`와 관리 대상용 `YEON-Managed-PC-v1.3.7.exe`를 **함께 업데이트**하세요.

- v1.3.7: **일반 화면 전송**은 관리자 화면을 관리 대상의 창으로 전송하고 마우스를 제한하지 않습니다. **집중 화면 전송**은 대상 PC의 전체 화면에 띄우되 현장 승인 및 ESC 긴급 종료가 필요합니다.
- 관리자·관리 대상 모두 사용자 제공 파란색 아이콘을 사용합니다.


## 관리자 파일 교환 · v1.3.7

왼쪽 관리 기능에서 **파일 보내기** 또는 **파일을 보내라고 명령하기**를 누릅니다.
기존에 등록된 컴퓨터 목록은 관리 버튼 오른쪽에 보이며, 컴퓨터를 클릭해서 대상을 선택합니다.
파일 보내기는 관리 대상 PC에서 저장 위치를 직접 지정한 후 전송됩니다.
파일 제출 요청은 관리 대상 PC에서 제출할 파일 1개를 직접 선택하면 관리자 PC에서 저장 위치를 선택합니다.
양쪽 모두 해당 PC의 8자리 코드 인증을 거친 뒤 이용할 수 있으며, 기본 용량 제한은 파일당 8MB입니다.
파일 목록 검색·무단 수집·자동 제출은 지원하지 않습니다.


## v1.3.7 — 8자리 번호만으로 자동 연결

관리 대상 PC에서 `공유 시작`을 누르면 8자리 일회용 접속 번호가 나옵니다. 같은 Wi-Fi에 있는 관리자 PC는 별도의 IP 주소 입력 없이 **번호만 입력**해 자동으로 관리 대상 PC를 찾고 로그인할 수 있습니다. 성공하면 원격 화면이 열리고 기존 관리자 ON/OFF, 파일 보내기, 제출 요청 등이 모두 동작합니다. 번호는 관리자 PC에 저장하지 않습니다.

이 기능은 인터넷 원격 중계 서비스가 아닙니다. 현재 관리자의 사설 네트워크 인터페이스와 같은 **/24 LAN(일반적으로 주소 앞 세 숫자 묶음이 같음)**에서만 자동 탐색합니다. 회사/학교의 게스트망, Wi-Fi 클라이언트 격리, 다중 서브넷 및 Windows 방화벽 제한에서는 탐색되지 않을 수 있습니다. Windows 방화벽에서 관리 대상 앱의 포트 8765를 개인 네트워크용으로 허용하고 두 PC를 같은 Wi-Fi에 연결하세요. 관리 대상 앱도 v1.3.7이 필요합니다. 일반 네트워크 HTTP 통신은 암호화되지 않으므로 신뢰할 수 있는 개인 LAN에서만 사용하세요.
