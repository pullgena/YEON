# YEON 원격 조정 — 관리자 v1.3.4

- 더블 클릭하면 관리 제어판을 자동 실행합니다.
- 왼쪽 **내 컴퓨터 목록**에서 저장된 관리 대상 PC의 이름을 클릭하면 해당 원격 조정 창이 열립니다. 이름은 8자리 PIN 인증 후 관리 대상 PC에서 안전하게 가져옵니다. IP 주소만 저장하며 PIN은 저장하지 않습니다.
- 해당 관리 대상 PC에서 명시적으로 **공유 시작**을 눌러야 접속할 수 있습니다. 같은 신뢰하는 LAN 내에서만 연결 가능합니다.
- 관리자 제어판에서 원격 입력을 **ON/OFF**로 관리합니다. OFF 시 화면만 보여 주며 기본 OFF입니다.
- 원격 화면에서 입력 칸(구글 검색창 등)을 클릭한 후 **키보드로 직접 타이핑**합니다. 한글 IME와 영문 입력 지원. 클릭으로 원격 화면에 키보드 포커스가 이동하며 빠른 조작도 지원합니다.
- 관리자 앱의 **X 버튼**을 누르면 프로그램은 종료되지 않고 **Windows 알림 영역(시스템 트레이)**에 남습니다. 트레이 아이콘을 클릭해 제어판을 다시 열거나 우클릭해서 연결 중지/완전 종료할 수 있습니다.
- **집중 화면 전송**은 관리 대상 사용자가 현장에서 승인해야 실행되며 ESC로 긴급 종료할 수 있습니다.
- 관리자 앱을 완전히 종료하거나 연결 종료하면 원격 제어 ON 권한을 해제합니다.

관리자용 `YEON-Remote-Admin-v1.3.4.exe`와 관리 대상용 `YEON-Managed-PC-v1.3.4.exe`를 **함께 업데이트**하세요.
