# YEON 원격 조정 — 관리자 v1.3.0

Windows 10/11용 **관리자 앱**입니다. 이전 `remote-control/` 폴더의 앱은 **관리받는 PC에서 화면 공유를 제공하는 호스트 앱**이고, 이 `remote-admin/` 앱은 별도의 **관리자/조종자 프로그램**입니다.

## v1.3.0 집중 화면 전송
관리자 앱에서 대상 PC에 먼저 접속하고 8자리 인증 코드를 입력한 뒤 **집중 화면 전송**을 누릅니다. 대상 PC 사용자가 직접 승인해야 관리자 화면이 대상 PC에서 전체 화면으로 표시됩니다. 관리 대상 PC의 마우스는 빨간 긴급 종료 버튼 영역으로 제한되며 ESC 키로도 종료할 수 있습니다. **원격 제어**를 누르면 집중 모드가 종료되고 관리자용 기존 원격 조정 창이 앞으로 나옵니다. 두 PC는 같은 LAN에 있어야 하며 전송 데이터는 현재 HTTP를 사용하므로 신뢰하는 네트워크에서만 이용하세요.

## 사용 순서

1. 관리받는 컴퓨터에서 기존 `YEON 원격 조정` 공유 앱을 켜고 **공유 시작**을 누릅니다.
2. 표시되는 주소와 8자리 접속 코드를 확인합니다.
3. 관리자의 Windows 컴퓨터에서 **`YEON-Remote-Admin-v1.3.0.exe`를 더블 클릭**합니다. 관리자 소프트웨어가 바로 실행되며 별도 브라우저를 수동으로 켤 필요가 없습니다.
4. 관리 대상 PC 주소(예: `192.168.0.10:8765`)를 입력하고 **원격 조정 시작**을 누릅니다.
5. 열리는 원격 조정 창에서 대상 PC의 **8자리 접속 코드**로 로그인합니다.
6. 화면 보기, 마우스, 키보드, 단축키 등을 사용합니다. 앱에서 **연결 종료**를 누르거나 대상 PC에서 **즉시 중지**를 누르면 연결이 끊깁니다.

관리자가 사용하는 앱을 켰을 때 *관리자 제어판이 자동 실행*되는 것이며 **관리받는 컴퓨터를 무단으로 켜거나 공유를 강제 시작하지는 않습니다**. Windows 시작 시 백그라운드 자동 실행은 구현하지 않습니다.

## 보안·지원 범위

- 관리자 앱은 Electron의 별도 보안 격리 창에서 대상 PC의 웹 조종 화면을 엽니다. 관리 대상 웹페이지에는 Node.js/시스템 API를 노출하지 않습니다.
- `http://사설 IPv4:8765` 또는 localhost만 허용하고 외부 인터넷 주소/임의 포트 이동을 막습니다.
- 기존 공유 PC의 PIN 인증, 같은 LAN 제한, 호스트의 수동 공유 시작/중지를 그대로 따릅니다.
- 통신은 HTTP(암호화되지 않음)입니다. 신뢰하는 개인 네트워크에서만 사용하십시오. 공용 Wi-Fi와 인터넷 포트 포워딩은 사용하지 마십시오.
- UAC/로그인 화면 또는 임의의 셸 명령은 원격 조작하지 않습니다.
- 해당 프로그램은 코드 서명이 없어 Windows SmartScreen 경고가 나올 수 있습니다.

## 빌드 및 테스트

```powershell
cd remote-admin
npm install
npm test
npm run build:win
```

실행 파일: `remote-admin/dist/YEON-Remote-Admin-v1.3.0.exe`

GitHub Actions는 해당 폴더/전용 워크플로의 변경 시 Windows에서 EXE를 빌드하고 `remote-admin-v1.3.0` 릴리스에 업로드합니다. 이전 공유용 릴리스 `remote-v1.0.1`은 유지합니다.
