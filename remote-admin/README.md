# YEON 원격 조정 — 관리자 v1.3.2

이번 버전의 **원격 제어 ON/OFF 버튼은 관리자 프로그램에 있습니다**.

1. 관리 대상 PC에서 수동으로 **공유 시작**을 누릅니다.
2. 관리자 앱 `YEON-Remote-Admin-v1.3.2.exe`를 열어 주소를 입력하고, 새로 뜨는 원격 화면 창에서 PIN 8자리로 로그인합니다.
3. 관리자 앱의 **원격 제어 ON**을 클릭하면 마우스·키보드 조작이 허용되고, **원격 제어 OFF**를 클릭하면 화면만 볼 수 있습니다.
4. 기본 OFF이며 ON/OFF는 로그인한 해당 관리자 세션에만 적용됩니다. 연결을 끊으면 OFF로 전환하려고 시도하며, 공유 종료/로그아웃/세션 만료 때 권한이 제거됩니다.
5. **집중 화면 전송**을 시작하면 대상 PC에 별도 현장 승인 요청이 뜨고 승인 시 전체 화면 표시됩니다. ESC 또는 종료 버튼으로 해제됩니다.

관리 대상 앱에는 ON/OFF 토글이 없지만 언제든 **공유 즉시 중지/완전 종료**가 가능합니다. 이는 사용자의 명시적 공유 시작과 8자리 코드 제공을 전제로 한 기능입니다.

같은 신뢰할 수 있는 LAN 전용이며 HTTP 전송은 암호화되지 않습니다. 인터넷에 포트를 개방하지 마세요.

빌드: `npm install && npm test && npm run build:win`. GitHub Release: `remote-admin-v1.3.2`.
