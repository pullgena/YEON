원격 제어 상태: 확인 중 (관리 대상 PC에서 ON/OFF 설정)

집중 화면 전송은 관리자 PC 화면을 관리 대상 PC에 크게 표시합니다. 관리 대상 사용자의 현장 승인 후 작동하며, 대상 PC에서 ESC로 즉시 중단할 수 있습니다.

대기 중

연결 방법

01 관리받는 PC에서 YEON 원격 조정 (공유용) 앱 실행

02 해당 PC에서 공유 시작을 눌러 주소와 8자리 코드를 확인

03 이 관리자 앱에 주소 입력 → 원격 조정 창이 자동으로 열림

04 열린 창에 8자리 코드를 입력하면 화면·마우스·키보드 사용 가능

같은 Wi-Fi/사설 네트워크에서만 연결 · 상대방의 동의 필요 · 인터넷 공개 연결 미지원
