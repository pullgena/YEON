# YEON Messenger v0.5.0

Windows에서 독립 실행되는 YEON 채팅 앱입니다. 시작 화면에서 두 가지 연결 방식을 선택할 수 있습니다.

## 1. 내 컴퓨터에서 시작
앱 시작 화면에서 **내 컴퓨터에서 시작**을 누르면 Windows 프로그램 내부에서 로컬 채팅 서버를 자동 실행합니다.
계정과 메시지는 `%APPDATA%\\YEON\\local-chat-data.json`에 저장됩니다. 로컬 서버의 접속 주소는 `127.0.0.1`이고 매 실행마다 임의 포트를 사용합니다. 다른 컴퓨터에서 자동으로 연결되지는 않습니다.

## 2. 공용 서버에 접속
**공용 서버에 접속**을 누르고 실제 운영 중인 서버의 HTTPS 주소를 입력합니다. 같은 서버 주소를 사용하는 사용자들은 계정 생성, 서버 초대 및 친구 DM을 공유할 수 있습니다.

**아직 YEON의 공식 공용 서버가 배포되지 않았습니다.** GitHub 저장소에 코드를 올리는 것만으로는 공용 서버가 생기지 않습니다. 외부 호스팅 계정/도메인 설정이 필요합니다.

## 공용 서버 배포 가이드
서버는 Node.js 20+에서 `npm run server`로 실행합니다. Render, Railway, VPS 등에서 Node 웹 서비스로 배포할 수 있습니다.

- 빌드 명령: `npm install --omit=dev`
- 시작 명령: `npm run server`
- 환경 변수: `PORT`는 호스팅이 제공하는 값 사용, `YEON_DATA_FILE`은 영속 디스크의 파일 경로 지정
- 헬스 체크: `/api/health`
- 반드시 HTTPS 사용

컨테이너 배포 시 제공된 Dockerfile도 사용할 수 있습니다. 반드시 `/data` 영속 볼륨을 제공하세요. 그렇지 않으면 서비스 재시작 시 사용자 계정과 메시지가 사라질 수 있습니다.

## 지원 기능
- 회원가입/로그인, 친구 요청/승인, DM
- 서버 생성, 초대 코드로 참가, 텍스트 채널
- 실시간 채팅, 로컬 저장
- Windows 설치형/포터블 EXE 빌드
- 서버 선택, 연결 재시도, Wi-Fi 설정 링크

## 소스 실행
```sh
npm install
npm start
```
웹 서버만 실행할 경우 `npm run server`를 실행하세요.

## 아직 필요한 보안 작업
현재 백엔드는 소규모 시험용 JSON 파일 저장 방식입니다. 외부에 공개 운영하기 전에 HTTPS, 속도 제한, 세션 만료, 사용자 차단/신고, 데이터 백업, 서버 권한 검증, 초대 코드 재발급, 개인정보 보호 정책 등 보완이 필요합니다. 음성/영상 채팅은 아직 없습니다.
