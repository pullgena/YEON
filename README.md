# YEON Messenger v0.4.0

독립적인 **클라이언트-서버 기반 채팅 앱**의 초기 버전입니다. 다른 사용자와 채팅하려면 모두 같은 공용 YEON 서버에 접속해야 합니다.

## 구현
- 계정 등록 / 로그인 (서버에서 scrypt 비밀번호 해시)
- 친구 요청 / 수락 및 1:1 DM
- 서버 만들기 / 초대 코드 참가 / 텍스트 채널 생성
- SSE 실시간 텍스트 메시지
- Windows Electron 설치형/포터블 EXE 빌드

## 서버 운영
서버 컴퓨터에 Node.js 20 이상을 설치한 뒤:
```sh
git clone https://github.com/pullgena/YEON.git
cd YEON
npm run server
```
서버는 기본적으로 3000번 포트를 사용하며, `PORT` 환경변수로 변경할 수 있습니다. 메시지와 계정 데이터는 `yeon-data.json`에 저장됩니다. 이 파일은 절대 공개 저장소에 올리지 마세요.

인터넷에서 사용하려면 서버를 실제로 배포하고 HTTPS 리버스 프록시를 연결해야 합니다. 아직 YEON의 공식 공용 서버는 배포하지 않았습니다.

## Windows 앱 연결
GitHub Actions에서 v0.4.0 EXE가 빌드되면 내려받을 수 있습니다. 연결 전 `%APPDATA%\\YEON\\config.json` 파일에 다음과 같이 실제 서버 주소를 입력하세요.
```json
{"serverUrl":"https://your-server.example"}
```
개발용 로컬 서버는 `http://127.0.0.1:3000`도 사용할 수 있습니다. 서로 다른 PC가 같은 서버에 접속해야 메시지가 공유됩니다.

## 개발 / 빌드
```sh
npm install
npm start
npm run dist
```

## 보안 및 제한 사항
이 앱은 초기 프로토타입이며 공개 운영 수준으로 보안 감사를 거치지 않았습니다. 비밀번호 재설정, 스팸 방지/요청 제한, 운영자 권한, 차단/신고, 파일 전송, 음성/화상 통화, 종단간 암호화 및 웹Socket이 없습니다. 데이터는 JSON 파일에 저장하므로 소규모 시험용입니다. 실제 공개 서비스 전 TLS, 인증 토큰 보관 개선, 입력 검증 및 관리 기능이 추가되어야 합니다.
