# YEON ✦

Discord에서 영감을 받은 실시간 커뮤니티 채팅 웹 앱입니다.

## 실행 (Node.js 20 이상)

```bash
npm start
```

브라우저에서 **http://localhost:3000** 에 접속합니다. 같은 네트워크 또는 배포된 서버 주소로 접속하는 사용자끼리 실시간 대화할 수 있습니다.

## v0.1.0 기능
- 어두운 Discord 스타일의 반응형 UI
- 여러 서버 및 텍스트 채널 생성
- 사용자 닉네임, 실시간 메시지 및 온라인 사용자 표시
- 메시지와 서버/채널 구성 JSON 파일 저장
- 의존성 없는 Node.js HTTP + Server-Sent Events 방식

## 주의 / 향후 개발
이 버전은 **초기 프로토타입**입니다. 계정 로그인, 비공개 채널 권한, 종단 간 암호화, 신고/관리 기능, 음성 및 영상 통화는 제공하지 않습니다. 닉네임은 인증되지 않아 사칭이 가능합니다. 인터넷에 공개하기 전 인증·권한 제어·요청 제한·콘텐츠 관리·HTTPS 등을 추가해야 합니다. 생성되는 `data.json`은 공유 저장소에 커밋하지 마세요.
