# YEON 원격 조정 — 관리 대상 v1.3.2

관리 대상 Windows PC용 공유 앱입니다. 이 버전은 **원격 제어 ON/OFF를 관리자 앱에서 설정**합니다.

1. `YEON-Managed-PC-v1.3.2.exe`를 실행해 **공유 시작**을 누릅니다. 화면 주소와 8자리 PIN이 표시됩니다.
2. 관리자 PC에서 `YEON-Remote-Admin-v1.3.2.exe`를 실행해 주소를 입력하고 PIN으로 로그인합니다.
3. **관리자 제어판**의 원격 제어 ON 버튼을 누르면 로그인된 해당 관리자 세션에서만 원격 입력이 활성화됩니다. 기본값은 OFF(화면만 보기)입니다.
4. 관리 대상 PC에는 원격 제어 ON/OFF 버튼이 없습니다. 관리 대상 PC 사용자는 언제든 **공유 즉시 중지**, 트레이 메뉴 **공유 즉시 중지** 또는 **완전 종료**로 전체 연결을 끊을 수 있습니다.
5. 집중 화면 전송은 관리 대상 PC 사용자의 현장 승인 후 사용 가능하며 ESC/빨간 종료 버튼으로 해제할 수 있습니다.

창의 X를 누르면 트레이 아이콘으로 숨겨집니다. 트레이 아이콘은 공유 중 상태를 보여 줍니다. HTTP 통신은 암호화되지 않으므로 신뢰할 수 있는 동일 LAN에서만 사용하세요. 인터넷에 8765 포트를 공개하지 마세요.

자동 빌드: GitHub `remote-managed-v1.3.2` 태그. Windows용 `YEON-Managed-PC-v1.3.2.exe`.
