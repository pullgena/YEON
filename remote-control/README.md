# YEON 원격 조정 v1.0.1 (Windows)

YEON의 다른 프로젝트와 구분되는 독립적인 **원격 조정** 앱입니다. 이 버전은 사용자가 명시적으로 **공유 시작**을 누른 Windows PC의 화면을 같은 Wi-Fi에 있는 휴대폰 또는 다른 PC의 브라우저에서 제어할 수 있게 해 줍니다.

## 지금 사용 가능한 구성

- **관리받는 컴퓨터(호스트)**: `YEON-원격-조정.exe`를 실행하고 `공유 시작` 버튼을 눌러야 합니다. 8자리 접속 코드와 주소가 화면에 표시됩니다.
- **관리하는 사람(조종자)**: 해당 주소를 크롬/엣지에서 연 다음 8자리 코드로 로그인합니다. 별도의 조종자용 EXE 없이 브라우저로 조작합니다.
- **추후 계획**: 관리받는 사람 전용 앱과 관리하는 사람용 앱을 분리할 예정입니다. 이는 아직 구현/배포되지 않았습니다. 현재 호스트 앱을 미래의 완성된 관리받는 사람용 앱으로 간주하면 안 됩니다.

## 제공 기능

- JPEG 기반 실시간 화면 갱신, 마우스 클릭/이동/드래그, 우클릭/스크롤
- 키보드 입력/단축키와 클립보드 이용한 한글 텍스트 입력
- 8자리 PIN, 접속 시도 제한, 세션 만료, 공유 종료 즉시 모든 접속 무효화
- 공유 중지 버튼과 창 닫기(사용자의 수동 제어)

## 사용법

1. **Windows 10/11** 컴퓨터에서 `YEON-원격-조정.exe`를 실행합니다.
2. `공유 시작`을 누릅니다. Windows 방화벽 질문이 나타나면 **개인 네트워크만** 허용합니다.
3. 다른 기기를 같은 Wi-Fi에 연결한 뒤 앱에 표시된 `http://192.168.x.x:8765` 형식의 주소로 접속합니다.
4. 8자리 코드를 입력하고 원격 조정합니다.
5. 관리받는 PC에서 `즉시 중지` 또는 창 닫기로 공유를 종료합니다.

## 안전상의 제한

- 인터넷 중계, 자동 부팅 실행, 숨김 실행, 파일 관리/원격 명령 실행을 제공하지 않습니다.
- HTTP 트래픽은 **암호화되지 않습니다**. 신뢰하는 개인 LAN에서만 사용하고 민감한 PC에는 HTTPS/TLS를 갖춘 정식 원격 데스크톱 제품을 사용하세요.
- 호스트 방화벽/라우터 설정에 따라 접근 경로가 달라지므로 포트를 인터넷에 공개하지 마세요.
- 다른 사람의 PC를 조정할 때는 상대방의 명시적인 동의를 받아야 합니다.
- UAC 보안 화면, Windows 로그인 화면은 조작할 수 없습니다.

## Windows에서 한 번에 EXE 빌드

ZIP 파일을 전부 압축 해제한 후 최상위 폴더에서 `BUILD-WINDOWS.bat`를 더블 클릭합니다. Python 3.12의 자동 설치가 필요할 수 있으며, 스크립트는 의존성 설치, 문법 검증, 서버 테스트, PyInstaller 빌드를 진행합니다. 완료 후 출력 위치는 다음과 같습니다.

`remote-control/dist/YEON-원격-조정.exe`

다음 명령으로도 빌드할 수 있습니다.

```powershell
cd remote-control
python -m pip install -r requirements.txt pyinstaller
python -m unittest discover -s tests -v
python -m PyInstaller --noconfirm --clean --onefile --windowed --name "YEON-원격-조정" --add-data "web/index.html;web" app.py
```

## GitHub 릴리스

저장소: https://github.com/pullgena/YEON

압축을 푼 폴더에서 `PUBLISH-GITHUB.bat`를 실행하면 GitHub 로그인/권한 확인 후 기존 저장소의 **`remote-control/`과 전용 빌드 워크플로 파일만** 갱신합니다. GitHub Actions에서 Windows 빌드를 수행하고 성공하면 `remote-v1.0.1` 릴리스를 생성하도록 구성했습니다.

기존 YEON 메신저나 다른 프로젝트의 소스 코드는 건드리지 않습니다. 워크플로 파일 업로드에는 GitHub 쓰기 권한과 workflow scope가 필요합니다. 빌드 성공 여부는 GitHub Actions에서 확인하세요. 릴리스 업로드 권한이 거부되는 경우에도 Actions 빌드 아티팩트에 EXE를 보관하도록 설정했습니다.

**참고:** 이 ZIP은 `.exe`가 포함된 완성된 Windows 설치 프로그램이 아니라, Windows에서 `.exe`를 빌드하도록 준비된 소스 패키지입니다.
