# YEON 원격 조정 — 관리 대상 v1.3.5

관리 대상 Windows PC용 공유 앱입니다. 이 버전은 **원격 제어 ON/OFF를 관리자 앱에서 설정**하며, 인증 후 관리 대상 PC 이름을 관리자 컴퓨터 목록에 표시하고 별도 입력 칸 없이 직접 원격 키보드 입력을 지원합니다.

1. `YEON-Managed-PC-v1.3.5.exe`를 실행해 **공유 시작**을 누릅니다. 화면 주소와 8자리 PIN이 표시됩니다.
2. 관리자 PC에서 `YEON-Remote-Admin-v1.3.5.exe`를 실행해 주소를 입력하고 PIN으로 로그인합니다.
3. **관리자 제어판**의 원격 제어 ON 버튼을 누르면 로그인된 해당 관리자 세션에서만 원격 입력이 활성화됩니다. 기본값은 OFF(화면만 보기)입니다.
4. 관리 대상 PC에는 원격 제어 ON/OFF 버튼이 없습니다. 관리 대상 PC 사용자는 언제든 **공유 즉시 중지**, 트레이 메뉴 **공유 즉시 중지** 또는 **완전 종료**로 전체 연결을 끊을 수 있습니다.
5. 집중 화면 전송은 관리 대상 PC 사용자의 현장 승인 후 사용 가능하며 ESC/빨간 종료 버튼으로 해제할 수 있습니다.

창의 X를 누르면 트레이 아이콘으로 숨겨집니다. 트레이 아이콘은 공유 중 상태를 보여 줍니다. HTTP 통신은 암호화되지 않으므로 신뢰할 수 있는 동일 LAN에서만 사용하세요. 인터넷에 8765 포트를 공개하지 마세요.

자동 빌드: GitHub `remote-managed-v1.3.5` 태그. Windows용 `YEON-Managed-PC-v1.3.5.exe`.

- v1.3.5: 일반 화면 전송은 현장 승인 뒤 창 모드로 표시되며 마우스 사용은 계속 가능합니다. 집중 화면 전송은 기존 ESC 긴급 해제를 유지합니다. 사용자 제공 YEON 아이콘을 적용했습니다.

### 원격 제어가 실패할 때

1. 관리 대상 앱의 **공유 시작**을 누르고 관리자 원격 화면에서 **8자리 코드**로 로그인합니다.
2. 관리자 제어판에서 **원격 제어 ON**을 누릅니다. (기본값은 OFF)
3. 보안상 대상 컴퓨터의 잠금 화면과 Windows UAC 승격 창은 조작할 수 없습니다.
4. 마우스가 화면 모서리에 있을 때 PyAutoGUI의 FailSafe가 작동할 수 있습니다. 대상 PC에서 마우스를 중앙으로 옮긴 뒤 재시도합니다.
5. 새 관리자/대상 앱을 모두 v1.3.5로 설치하고, 같은 개인 Wi-Fi에서 테스트합니다.

새 버전에서는 마우스·키보드 명령을 전송 순서대로 처리하고 입력 실패 원인을 표시합니다.
