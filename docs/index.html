3단계로 설치하기

모드마다 설치 대상과 필수 모드가 다르므로 상세 정보를 먼저 확인해 주세요.

01

버전 확인

마인크래프트 버전(26.2 또는 26.3)과 Fabric Loader, Java 요구 사항을 확인하세요.

02

JAR 다운로드

모드 카드에서 공개 릴리스의 JAR 파일을 다운로드합니다. 릴리스가 없는 모드는 아직 내려받을 수 없습니다.

03

mods 폴더에 설치

필요한 Fabric API 및 의존성과 함께 JAR를 mods 폴더에 넣고 게임 또는 서버를 재시작하세요.

※ 이 사이트는 모드의 정상 작동을 보증하지 않습니다. 현재 일부 모드는 시험 개발 단계입니다. 기존 월드와 서버는 먼저 백업하고 테스트해 주세요. GitHub에서 소스 코드 다운로드(ZIP)는 배포용 JAR 파일과 다릅니다.
