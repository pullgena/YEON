# Blade Dimensions v0.2.4

## v0.2.4
설정 화면에 실제 Wi-Fi를 건드리지 않는 **Wi-Fi 상태 테스트 모드**를 추가했습니다.

- 큰 Wi-Fi 아이콘 표시
- 슬라이더로 전파 세기 0~4칸 조절
- 4칸: 강함 → 경고 없음
- 3칸: 보통 → 경고 없음
- 2칸: 약함 → 상단 `와이파이가 안좋습니다.` 경고
- 1칸: 매우 약함 → 상단 경고
- 0칸: 기존 검은 `와이파이가 없어요` 화면
- `실제 상태로 돌아가기` 버튼으로 즉시 실제 네트워크 감지 모드 복귀

테스트 모드가 켜진 동안 실제 네트워크 품질 감지는 테스트 상태를 덮어쓰지 않습니다.
